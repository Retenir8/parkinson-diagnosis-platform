# 系统架构

## 目标结构

```text
Vue 3 / TypeScript / Vite
├─ 浏览器开发：Vite → FastAPI
└─ 桌面开发：Tauri WebView → FastAPI
                               │
                               ├─ 患者与资料文件仓库
                               ├─ 视频分割与本地归档服务
                               ├─ 手部/腿部评估任务编排器
                               ├─ 整体姿态模块适配器
                               ├─ 手部模块适配器
                               ├─ 腿部模块适配器
                               ├─ 智能鞋垫模块适配器
                               └─ 结构化报告聚合器
```

## 当前已经实现

- Vue/Vite 浏览器模式和 Tauri 桌面壳共用同一套页面。
- 患者创建、检索、查看和本地 JSON 持久化。
- 浏览器文件流式上传；Tauri 模式可登记本地文件路径。
- 独立的视频分割工作页：导入普通视频或 RealSense `.bag`、生成浏览器预览、人工标记时间段，并把原始文件与 CSV/JSON 保存到同一归档目录。手部任务可设置裁剪区域 `crop_region`，保存到 `segments.json` 顶层。
- 每份资料在上传时绑定 `module_id + input_slot`。
- 评估任务按模块保存输入映射和对应的独立输出记录。
- 四类模型的统一描述、输入槽、校验和结构化结果接口。
- 整体姿态、手部与腿部模型的后台并行推理；每个模型先写入独立 JSON，线程全部结束后再合并评估主记录。
- 整体姿态使用 RealSense `.bag` 与人工分段清单，只提取 `task_type=walk` 的 17 项特征，再调用 walk17 三分类模型；每个 walk 片段生成骨架标注 WebM。
- 手部运动：三任务（对指/轮替/握拳）共享 MediaPipe Hands 关键点；支持可选分段模式（`segments.json` 带 `task_type`），每段只运行对应动作的检测与评分，每段生成独立标注 WebM；握拳/轮替检测带抗抖动状态机（方向持续确认、handedness 翻转抑制）。
- 腿部运动：脚趾拍地/抬腿各一输入槽，MediaPipe Pose 检测，每个任务生成标注 WebM。
- 采集评估页按已上传模块展开结果：整体姿态骨架视频/17特征/概率，手部与腿部任务分项指标与标注视频（单播放窗口 + 下拉切换分段）。
- 评估输出文件的受限只读接口，不允许客户端指定任意磁盘路径；支持按资料/分割项目/评估输出/评估整体 DELETE 清理。
- 存储去重：≥ 1 MB 的同内容文件以硬链接去重（`data/content_index.json` 索引）；删除时只移除索引，物理空间由文件系统回收。
- 推理前预检输入资料在本地磁盘的可读性，缺失即拒绝启动。
- 结构化报告中心：患者信息、各模块详细指标和可追溯的健康/轻度/中重度研究性分层；删除报告 = 删除对应评估记录。
- 采集评估页 KeepAlive 缓存：切换页面后保留文件列表、评估与推理进度状态。

## 当前明确没有实现

- 没有执行智能鞋垫模型推理。
- 没有跨模块综合评分或正式临床结论。
- 没有实时摄像头/RealSense 边采集边推理；当前“实时指标”是写入推理后骨架视频的逐帧指标。
- 没有报告 PDF/Word 生成。
- 没有数据库、云同步、用户账号、权限或加密。
- 没有把 Python 服务打包为 Tauri sidecar。

## 运行模式

### 浏览器开发

`npm run dev:web` 同时启动本地 FastAPI 和 Vite。浏览器选择的文件会复制到 `data`，并保存其所属模块和输入槽。

### Tauri 开发

`npm run dev:desktop` 同时启动本地 FastAPI 和 `tauri dev`。Tauri 文件选择器可直接登记大型 `.bag` 的绝对路径，避免复制。

### 最终桌面包

未来用 PyInstaller/Nuitka 把 Python 服务构建成 sidecar，由 Tauri 启动、健康检查和关闭。sidecar 文件名、端口令牌、资源路径和 RealSense Runtime 尚未确定，因此当前 `tauri.conf.json` 没有伪造 `externalBin` 配置。
