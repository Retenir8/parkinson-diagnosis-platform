# 模型接入信息模板

每个模型负责人提交一份副本并填写，不能确定的字段写“待确认”。

## 基本信息

- 模块名称：
- 负责人：
- 模型版本：
- 模型格式：
- Python/运行时版本：
- CPU/GPU/驱动要求：
- 依赖锁文件位置：
- 模型文件及许可证：

## 输入协议

- 支持的数据类型：
- 动作/采集任务：
- 视频视角、分辨率和帧率：
- 是否需要分段：
- 数据字段、类型与单位：
- 必填元数据：
- 输入质量最低要求：

## 输出协议

- 指标名称、类型、单位：
- 分数名称、范围与临床含义：
- 置信度/概率：
- 质量字段：
- 警告条件：
- 可视化形式：
- 输出文件：

## 性能与测试

- 目标硬件：
- 样例时长：
- 推理耗时：
- 峰值内存/显存：
- 匿名测试样例位置：
- 样例期望输出：
- 失败/异常样例：

## 融合约束

- 能否独立解释：
- 与其他模块的时间对齐要求：
- 缺失输入时的行为：
- 是否允许重算：
- 是否需要人工复核：
